## 建議複審重點
1. `verify()` 沒有任何快取路徑；`ask()` 在驗證失敗時於 `http.request` 之前就丟出錯誤。
2. 回應核對的順序：解析 → 量測回報 → model 身分 → remote 欄位 → 內容型別。
3. 排程器把 adapter 的錯誤一律轉成規則台詞（`reason: error`），Hub 只保存規則台詞。
