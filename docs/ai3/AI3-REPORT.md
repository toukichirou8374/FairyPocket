## 3. 語音問題的根本原因（證據）
詳見證據檔。四個主因：
1. **同一句送兩次**：中途結果先當作說完，370 毫秒後又來了較長的完成結果（「1時」→「1時マイク」）。
2. **家人的話被當成她自己的回音丟掉**：舊比對只看「字的重複比例」，日文假名跟她的長句幾乎都重疊（11-15 有 2 次，家人得重講）。
3. **她說話時（神經語音 6～12 秒＋1.5 秒）所有結果直接丟掉**：她每 15～20 秒說一次，約一半時間聽不到；家人插話整句消失，只剩尾巴（「行く」「テレビ」）。
4. **AI 在想時家人又說話**：被降級成「發生的事」另外問一次，兩個回答重疊。

另外檢查出的次要問題：停掉的辨識物件還會送舊結果；空的完成結果沒有區分；`audio-capture`（iPhone 播放語音時常見的暫時占用）一次就永久放棄；自動重新開始失敗兩次後就默默停住，沒有任何通知。

## 4. 語音修正內容
| 問題 | 修正 | 檔案 |
|---|---|---|
| 重複送出 | `FinalGate`：3 秒內一樣或是上一句的一部分＝不送；更長的修正版換掉還沒回答的那一句（舊回答作廢，記 `stale`） | `src/life/hearing.ts`、`main.ts` |
| 回音誤判 | `echoOf`：相鄰兩個字比對（≥0.5）或包含；只比最近 30 秒 | `hearing.ts`、`persona.ts`（`isEcho` 改用它） |
| 她說話時聽不到 | `HeldFinal`：完成結果先留著（只留最新一句、10 秒內），她說完再處理；用比較寬的回音標準（0.3）濾掉她自己的聲音 | `hearing.ts`、`main.ts` |
| 回答重疊 | AI 在想時家人的話保留成「說的話」，想完馬上回答 | `main.ts`（`lifePendingChat`） |
| 舊結果 | 停掉／換新的辨識後，舊物件的結果與錯誤一律不理 | `speech.ts` |
| NoMatch | 空的完成結果、`nomatch` 事件記成 `nomatch`，不送 AI | `speech.ts` |
| 暫時占用 | `audio-capture` 連續 3 次才放棄（有結果就歸零）；沒有權限才是一定停 | `speech.ts` |
| 默默停住 | 自動重新開始失敗時 0.3／1／2.5／5 秒再試，還是不行就通知（`stalled`） | `speech.ts` |
| 停掉時遺失 | 停掉時還沒送出的中途結果當作說完 | `speech.ts` |

非生命模式（原生 6 種、AI 互動 3 種）的行為不變：她說話時照舊不聽（`HeldFinal` 只在生命模式）。

## 6. 三種生命模式
- **文字生命**：不開麥克風（沒有改）。打字的話走同一條路由；AI 在想時打的字也不會再被降級。
- **語音生命**：上面全部的語音修正。
- **動態生命（鏡頭）**：麥克風照舊；鏡頭畫面照舊只在「讓 AI 看鏡頭」開關打開時、只送家裡電腦。**Claude 永遠拿不到畫面，也拿不到畫面的文字描述**（送 Claude 的狀態把 `vision`、`sight` 清空）。

## 7. 三種語言
- 辨識語言照舊固定為設定的語言（zh-TW／ja-JP／en-US），繁體中文保持。
- 測試涵蓋三種語言的辨識流程、回音判斷、複雜度判斷、「已經做好了」的偵測。
- 名字＋關鍵字的小助手指令規則沒有改；模稜兩可的指令照舊不執行（`detectCommand` 沒有動）。

## 9. 路由規則（`src/brain/router.ts`，規則，不問 AI）
- 每次只選一個主要來源，失敗才依序換下一個；**不會同時呼叫幾個付費模型**，不會用貴的模型做路由。
- 自己決定、看到聽到、家人做了什麼：一律家裡 AI（不花錢；不會因為換來源而重複產生生命經驗）。
- 家人說的話：**預設 Claude 優先（製作人 2026-11-17 決定）**＝「Claude → 既有雲端 → 本機」，Claude 失敗、沒開或預算用完才換下一個；自動＝簡單的話「既有雲端 → 本機」，需要想的話「Claude → 既有雲端 → 本機」。Claude 沒打開時**跟以前完全一樣**（雲端 → 本機）（手機每 10 分鐘問一次家裡電腦的狀態，狀態不花錢）。
- 預算用完、被限流（依 Retry-After）、沒開、沒金鑰：Claude 暫停一段時間，直接用原本的 AI。
- 沒有網路：不問任何 AI（照舊安全待機）。
- 範圍：Claude 只接在三個 AI 生命模式；AI 互動模式（非生命）照舊。

## 12. 費用控制
- 後端強制每天／每月上限（預設每天 US$0.30、每月 US$4，約 45／600 日圓；`private/claude.txt` 可改）。**呼叫前用最壞情況估價**（輸入字數÷2 當 token、輸出用上限），超過剩下的額度就不呼叫。
